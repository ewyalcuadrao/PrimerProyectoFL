# Primer proyecto de Federated Learning

Proyecto experimental con TensorFlow Federated.

## Preparar el entorno

```bash
python3 -m venv tff_env
source tff_env/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Ejecutar la prueba

```bash
python imports.py
```

El script comprueba que TensorFlow Federated puede ejecutar una computación federada mínima.
